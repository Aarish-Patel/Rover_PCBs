# Rover_PCBs

Modular PCB stack for Mars Rover Manipal's rover, designed for the European Rover Challenge (ERC) 2025 — a panel of multi-layer boards integrating high-current motor drivers, logic level shifters, and buck/boost power management, with differential-pair routing for high-speed communication lines.

This is a **team contribution** — designed and developed collaboratively as part of the Mars Rover Manipal electronics team, not a solo project.

**Tools:** Altium Designer
